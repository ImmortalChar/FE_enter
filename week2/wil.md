React라는 새로운 툴에 대해서 가볍게 배우는 시간을 가졌다.

# 개요
React는 JavaScript 라이브러리로서 코드를 더 편하게 관리할 수 있게 해준다.

# 실습
실습을 통해 이미 만들어진 웹 파일을 조금 수정하였다.

1. 변수 수정
app.jsx 파일 상단에 있는 javaScript로 선언된 변수들(username 등)을 원하는대로 수정했다.
변수의 내용을 수정하는 것이기 때문에 원래 게시글에서 해당 내용만 변화를 줄 수 있다.

2. 이미지 변경
이미지를 첨부하는 방식은 기존 html과 차이가 없다. (src = "(경로)")
해당 부분에서 이미지만 변경해주었다.

3. 원하는 텍스트 단락 추가
이 것도 html의 방식과 동일, <(태그명)>으로 생성하여 활용하면 된다.
다만 줄 바꾸기의 경우 '<br>' 만 사용하면 그만이었던 반면 React에서는 '<br />로 사용해야 하는 불편함이 존재한다.
